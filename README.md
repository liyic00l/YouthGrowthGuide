# 青少年高性价比成长指南（男孩-女孩双轨版）

**用最少的钱、时间和精力，帮 10—18 岁中国普通家庭青少年守住健康、钱包与人身自由。**

本指南首版共收录 **64 条**原创循证行动建议（其中 A 级硬证据 **46 条**、B 级 **16 条**、C 级 **2 条**；通用核心 **41 条**、男孩必看 **11 条**、女孩必看 **12 条**，累计一手期刊论文与政府官方文件外链 **107 条**）。

全书专门面向**中国大陆 10—18 岁（小学高年级至高中/中职阶段）普通家庭青少年及家长**编写，所有法律、医疗与资助条目均严格对照截至 **2026 年**的最新临床医学指南、国家现行法律法规与教育部资助政策原文核实。

> **使用说明**：这不是一份必须全部打勾的任务清单，而是一本随时翻查的避坑与行动菜单——挑走一两条用在自己身上就算赚到。遇到急症、重病或具体法律纠纷时，请第一时间前往公立医院急诊或向专业律师、公安机关求助。
