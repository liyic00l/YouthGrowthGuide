## 每条建议的标准格式

每条建议均严格按照 6 大核心字段规范输出：
- **成本**：花多少钱、花多少时间、需要多大毅力（优先推荐 0 元或国家医保、公立医院替代方案）。
- **说人话**：120 字以内精炼白话，直击本质，初中生与忙碌家长一读就懂。
- **收益**：保留真实临床试验数据、统计学指标（如发病率降幅、置信区间）与最新法规条款号。
- **证据等级**：**A 级**（RCT大样本试验/权威临床指南/现行国家法律原文）、**B 级**（专科指南或优质队列研究）、**C 级**（专家安全共识）。
- **来源**：一手期刊 DOI 链接或国家政府官网权威外链。
- **备注**：包含实操细节、禁忌提醒与针对家长的核心沟通话术（`【直接转给爸妈看】：...`）。

## 本地运行与构建

本项目设计为**完全离线可用、无任何外部商业依赖**：

```powershell
# 1. 运行自动化全书字段与质量校验脚本
powershell -ExecutionPolicy Bypass -File tools/verify-items.ps1

# 2. 重新编译生成单文件离线 HTML
powershell -ExecutionPolicy Bypass -File tools/build-offline.ps1
```

生成后的 `dist/YouthGrowthGuide_单文件离线版.html` 可直接通过微信、U盘传给家长与学生，在任意无网络电脑或手机浏览器中双击秒开检索。
