### 为什么会有这个指南？

中国有上亿中学生与背后数千万焦虑的工薪家庭。在初中到高中的成长关键期，家长和孩子最常面临四类毁灭性风险：
1. **伪勤奋陷阱**：每天刷题熬夜到凌晨1点，考试依然不会做，陷入自责与抑郁；
2. **手机与算法剥夺**：多巴胺被短视频劫持，注意力断崖式下滑，亲子关系剑拔弩张；
3. **法律盲区与欺凌**：因为不懂刑法年龄线沦为电信诈骗“洗钱跑分工具人”（帮信罪），或者遭遇霸凌不敢反抗甚至被诱导轻生；
4. **家庭财产被割**：动辄几千上万元的“天价志愿规划卡”、“治愈近视仪”，或免密支付被几分钟扣光数万元养老钱。

**本书彻底剔除任何个人用药与自选医疗干预风险**，严守安全底线。全书 51 条建议只引**现行国家法律法规、教育部官方政策、中央网信办专项通报与顶刊认知心理学元分析**，每一条都明明白白写清成本、算清收益，并贴心提供**【直接转给爸妈看】**的沟通话术。

> **不用全做**：挑走适合自己的一两条用在身上就算赚到。

## 证据分级标准

全书严格拒绝“坊间偏方”与个人经验主张，条目分级标准如下：
- **A 级硬证据（共 44 条，占比 86%）**：
  - 中华人民共和国现行法律法规原文（如《民法典》《刑法修正案（十一）》《未成年人保护法》《治安管理处罚法》2026版）；
  - 国务院、教育部、财政部、中国人民银行现行行政法规与规章；
  - 国际高水平认知心理学随机对照试验（RCT）大样本元分析（如 Dunlosky 2013、Roediger 2006、Rohrer 2015）。
- **B 级硬证据（共 7 条，占比 14%）**：
  - 专科教育共识、国家权威心理危机干预中心规范（如 12356、12355 规范）。
