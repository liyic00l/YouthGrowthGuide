## 每条建议长这样

每条建议均以动词开头的具体行动为标题，标明`[通用]` / `[男孩必看]` / `[女孩必看]`与`[自己就能做]` / `[找爸妈一起办]`，固定包含六栏：
- **成本**：花多少钱、多少时间、需要多大毅力（超 500 元项目标出公立医院或国家免费替代方案）。
- **说人话**：2 到 4 句、120 字以内，第二人称「你」平视语态，初中生一遍读懂。
- **收益**：保留原始文献数据、置信区间、人群年份与 2026 最新法律法规条款号，供核对。
- **证据等级**：**A 级**（荟萃分析/大型队列/RCT 或现行国家法律法规原文）、**B 级**（临床技术指南或单一/小样本研究）、**C 级**（公认安全与教育共识）。
- **来源**：一手期刊论文 DOI 或政府官网原文链接。
- **备注**：适用边界、反方争议（以「争议」开头）、维权取证过程成本及`【直接转给爸妈看】`话术。

## 四种资源与双轨设计

1. **寿命与健康终点**：不可逆的发育窗口（骨龄闭合前、恒牙萌出期、睾丸/卵巢扭转黄金 6 小时）与意外伤亡预防。
2. **时间与精力**：拒绝假努力与手机注意力残留，用随机试验证实的认知科学方法学习。
3. **普通家庭的钱**：防充值打赏与教育医疗智商税，吃透国家免学费、免费疫苗、助学金与贴息助学贷款。
4. **人身自由**：牢记 12/14/16 周岁刑责线、2026 年新《治安管理处罚法》行政拘留线和「两卡」帮信罪红线。
