# 中国家庭中考/高考冲刺与青春期常备医药箱配置清单

> **编写背景**：中考与高考是青少年成长阶段体能与心理负荷的最高峰。许多家庭要么盲目听信非正规补品、购买无临床证据的“提神益智药”，要么在孩子突发感冒、腹泻、发烧、痛经时手足无措，甚至因为吃错药（如同时混服对乙酰氨基酚与布洛芬造成严重肝肾损伤，或考前误服含强嗜睡成分的感冒药导致考场昏睡）抱憾终身。
>
> 本清单由执业临床医生与药师指南严格核实，专为 **10—18 岁中学生普通家庭** 设计，全套药品均能在正规公立医院或平价大药房凭 OTC（非处方药）购齐，整套花费通常在 **80~150 元** 之间，拒绝一切智商税。

## 一、 考前冲刺与突发状况对症应急药（按症状备药）

| 场景与症状 | 推荐规范药品（国药准字OTC） | 用法与关键考场禁忌 | 绝对避雷与智商税打假 |
| :--- | :--- | :--- | :--- |
| **突发痛经（女孩必看）** | **布洛芬缓释胶囊**（0.3g/粒）或 **布洛芬混悬液** | **铁律**：在月经来潮前数小时或刚感到隐痛时，**饭后随餐立即服用1粒**。提前阻断子宫前列腺素致痛，按疗程吃1-2天。 | 严禁等到剧痛难忍打滚时才吃（此时致痛物质已大量释放，起效缓慢）；严禁空腹大量服用以防胃黏膜损伤；严禁盲目购买高价“暖宫贴”、“痛经中药调理丸”（无RCT临床止痛证据）。 |
| **突发高热/头痛（体温>38.5℃）** | **单方对乙酰氨基酚片**（0.5g/片） 或 **单方布洛芬缓释胶囊**（备选其一） | 体温超 38.5℃ 且伴有全身酸痛时服用 1 剂。间隔时间严格不小于 4~6 小时，24 小时内服用不超过 4 次。 | **致命禁忌**：**绝对严禁将对乙酰氨基酚与布洛芬同时混吃或交替服用**！严禁叠加吃含有对乙酰氨基酚成分的复方感冒药（如999感冒灵、白加黑、快克等），叠加会导致扑热息痛过量诱发急性肝坏死竭。 |
| **急性肠胃炎/考前紧张腹泻** | **蒙脱石散** + **口服补液盐散（III）** | 腹泻初期先冲服蒙脱石散1袋（吸附肠道病毒与毒素）；水样便频繁时，必须严格按 250ml 温水冲服口服补液盐散（III）预防脱水与电解质紊乱。 | 严禁考前滥用阿莫西林、诺氟沙星（18岁以下未成年人骨骼发育期禁用氟喹诺酮类抗生素）；考前突发紧张性肠易激综合征不要慌，多饮温水与口服补液盐即可。 |
| **过敏性鼻炎/荨麻疹（打喷嚏眼痒）** | **氯雷他定片** 或 **盐酸西替利嗪片**（第二代无嗜睡/低嗜睡抗组胺药） | 每日 1 次，每晚睡前服用 1 片。对花粉柳絮、尘螨过敏引起鼻塞、连续喷嚏、皮肤瘙痒有效。 | **考场大忌**：**绝对严禁在考前白天服用第一代抗组胺药（如扑尔敏、氯苯那敏、苯海拉明）**！扑尔敏极易穿透血脑屏障产生强烈中枢嗜睡、反应迟钝与注意力涣散，会直接毁掉考场答题状态。 |
| **胃酸过多/反酸烧心/神经性胃痛** | **铝碳酸镁咀嚼片**（如达喜） | 饭后 1-2 小时或突发胃痛烧心时**充分嚼碎后吞服** 1-2 片。中和胃酸并保护胃黏膜。 | 严禁整片用水直接吞下（咀嚼片必须嚼碎才能形成网状物理保护膜）；若伴随剧烈绞痛、腹肌板状僵硬，立即去急诊排查急腹症，勿拖延。 |

## 二、 青春期外伤与运动损伤急救包（物理耗材）

青少年处于体育中考、篮球足球剧烈对抗期，外伤常备耗材必须摒弃老一辈淘汰的错误做法：

| 耗材名称 | 规格与建议 | 规范使用方法 | 避坑提醒 |
| :--- | :--- | :--- | :--- |
| **医用碘伏消毒液 / 独立碘伏棉棒** | 100ml瓶装 或 独立灭菌双头棉棒 | 伤口周围由内向外消毒，温和不刺激粘膜，不影响结痂愈合。 | **彻底淘汰**：紫药水（甲紫溶液，有潜在致癌风险国家已淘汰）、红药水（含汞毒性且易造成皮肤色素沉着）、75%医用酒精（严禁直接倒在破溃开放伤口上，产生剧烈剧痛并灼伤肉芽组织）。 |
| **无菌医用棉签与创可贴** | 透气型防水创可贴、独立无菌敷贴 | 用于微小表浅擦伤止血与阻挡外界灰尘，建议每天更换保持干燥。 | 较深、较脏、被生锈铁钉刺伤的伤口**严禁包扎密封**（密闭厌氧环境极易滋生破伤风梭菌），必须敞开并于24小时内就医。 |
| **高弹性自粘绷带 / 弹性运动绑带** | 宽 5cm 或 7.5cm 自粘型 | 运动扭伤、脚踝关节韧带拉伤时加压包扎，限制关节异常活动度。 | 缠绕时切忌过紧导致远端肢体发紫缺血、麻木；包扎后检查脚趾/手指血液回流情况。 |
| **一次性医用冰袋（免冷冻速冷冰袋）** | 击打捏破内胆即冷型（常温保存备用） | 运动扭伤、软组织挫伤、下腹撞击后**前48小时内冷敷**，每次15-20分钟。 | **大忌**：扭伤急性期（前48小时）**严禁使用红花油、活络油剧烈揉搓热敷**！热敷会加剧局部毛细血管扩张与内出血，导致脚踝肿成“紫茄子”。 |

## 三、 绝对不要买的“考前神器”与伪科学智商税黑名单

1. **“聪明药”/“提神益智片”（阿得拉、利他林、莫达非尼等）**：
   - **实质**：全部属于国家严格管制的第一类精神药品（中枢神经兴奋剂，成分与冰毒结构高度类似）！
   - **危害**：长期私自滥用会造成不可逆的神经耐受性、极度抑郁、幻觉妄想、厌食甚至猝死。中学生私自购买网络走私的利他林涉嫌非法持有毒品。
2. **“考前吸氧瓶/便携式制氧器”**：
   - **医学事实**：呼吸道正常的健康青少年在常压空气中血氧饱和度通常在 98%-99%，根本不存在缺氧问题。盲目吸入高浓度纯氧反而可能诱发脑血管收缩甚至氧中毒，纯属商家利用考生家长焦虑收割的百元塑料瓶。
3. **“深海鱼油高浓度DHA/银杏叶脑力胶囊”**：
   - **医学事实**：多项国际大样本 RCT 临床研究证实，给智力发育正常的青少年额外超剂量补充 DHA，对短期内提高考场分数、逻辑推理能力**无任何统计学显著改善**。考前最补脑的动作是保证每天 8 小时充足睡眠，让大脑在海马体进行记忆固化。

## 四、 家庭药箱安全管理三铁律

1. **每年立夏与立冬两次清理过期药**：
   - 变质、受潮变色、过期的药品化学性质不稳定，毒性倍增，坚决丢入有害垃圾桶。
2. **保留原包装盒与完整说明书**：
   - 切忌将药片抠出混装在无标签小盒中。必须保留说明书上的【用法用量】与【不良反应/禁忌】供紧急核对。
3. **置于阴凉干燥避光处（常温 10-25℃）**：
   - 严禁放置在阳光暴晒的阳台窗台或潮湿的浴室柜内。
