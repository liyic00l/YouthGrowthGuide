# 中国青少年与普通家庭 TOP 1000 调研大盘与蒸馏 TOP 500 核心题库架构

## 一、调研样本大盘与蒸馏方法论

### 1. 调研数据源底盘（1000 问构成）
本题库基于中国大陆 10—18 岁（小学高年级至高中/中职）普通家庭青少年及家长的真实生活场景，系统聚合了：
- **医疗卫生与疾控**：国家卫健委儿童青少年体检数据、全国中小学视力监测、口腔流行病学调查、常见运动损伤。
- **教育与认知科学**：中高考大纲要求、认知心理学提取练习（Retrieval Practice）、中职贯通与普通高考志愿录取数据。
- **司法与治安实践**：最高人民检察院涉未成年人网络犯罪治理白皮书、公安部反诈中心电诈案件类型分布、2026 最新《治安管理处罚法》司法审判实务。
- **家庭教育与消费黑榜**：消协未成年人网络退款纠纷、黑产视力仪/增高针虚假宣传通报、饭圈集资乱象。

### 2. 蒸馏准则（从 1000 问到 500 问）
1. **剔除“低频/罕见极重症”**：完全剔除睾丸扭转、卵巢扭转、恶性肿瘤等发生率极低的非普遍场景。
2. **剔除“吓人/脱离中学生日常”**：完全剔除成人艾滋病阻断（PEP）、吸毒贩毒细节等可能引起过激恐慌的内容，置换为破伤风针接种、乙肝抗体复查、生锈钉扎伤清创等校园日常。
3. **“家长出资决策 + 学生离线行动”双轨过滤**：只保留普通家庭真正**能花得起、防得住、用得上**的高性价比硬核条目。
4. **动词开头与循证对齐**：每一个 Q&A 背后必须能推导出一个符合国家现行法律法规（截至 2026 年）或临床指南的“动词行动建议”。
