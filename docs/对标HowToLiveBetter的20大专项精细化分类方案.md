# 《青少年高性价比成长指南》：对标 HowToLiveBetter 的 20 大专项精细化分类方案

## 一、为什么 7 大类依然“不够用”？

《HowToLiveBetter》之所以大获成功，很重要的一点是它**不搞高度概括的“大箩筐”（如“生活篇、工作篇”），而是做了整整 34 个极其具体的专项微场景**（如《01-不要早死》、《06-反面清单》、《14-账号与信息安全》、《24-看病》、《34-家里的常备药别吃出事》）。

**如果只有 7 个大类：**
- 每个分类塞入 60~70 条内容，像一本大杂烩百科全书，家长要翻找“近视怎么办”，必须在混着骨折、烫伤、长高的百页大文件里大海捞针；
- **颗粒度太粗，丧失了“精准击中具体焦虑”的锐度**。

**中国普通家庭父母每天面对孩子的具体烦恼，是高度垂直分化的：**
- 眼睛是眼睛，牙齿是牙齿，急诊是急诊；
- 手机沉迷是手机沉迷，理科开窍是理科开窍；
- 校园欺凌是法律维权，不想上学是心理躯体化；
- 高考报志愿是升学算账，初中分流去职校是另一条路。
